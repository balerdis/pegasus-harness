
## Issue Tracker and Wiki

An organisation's own issue tracker reaches this session through Atlassian's server. What that server exposes is Atlassian's to decide, so take the tools you are actually offered as the answer. Follow `{{skills_root}}/_shared/mcp/jira-convention.md` for what to read, what counts as evidence from a ticket, and the rule that separates a write someone asked for from one that merely seemed tidy -- nothing destructive is withheld here, so that line is the whole of the protection. If that path is missing or unreadable, say so and read only; write nothing through this server without it.
