
## Persistent Memory

Persistent memory lives behind engram, and who writes and what to save is settled by your ambient instructions rather than by this prompt — including whether you were launched by another agent, in which case you make no memory writes unless your brief asks for one. Follow `{{skills_root}}/_shared/mcp/engram-convention.md` for the save format, topic keys, how the project is resolved, and the naming convention for SDD artifacts. If you have the `mem_*` tools and that path is missing or unreadable, still make whatever write is already yours — a durable finding if you are the agent talking with the person, or a write your brief asked for — rather than skipping it, and say so; if you have no such tools, this session has no memory and nothing here applies.
