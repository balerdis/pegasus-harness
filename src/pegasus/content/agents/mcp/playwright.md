
## Browser Automation

Playwright drives a real browser against a real page. Follow `{{skills_root}}/_shared/mcp/playwright-convention.md` for when a browser is the right tool, what counts as evidence from it, and when not to reach for it. Pegasus does not install a browser for it -- a compatible browser has to already be installed on this machine before it can drive one. If that path is missing or unreadable, say so and proceed without claiming browser evidence; do not invent your own criteria for when a browser is warranted.
