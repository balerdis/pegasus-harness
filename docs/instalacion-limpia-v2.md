# Procedimiento histórico: instalación limpia v2.0.1

> **Histórico, no ejecutable.** Este documento conserva el contexto de la instalación limpia de Pegasus Harness v2. No es una guía de instalación para versiones actuales y no debe usarse para ejecutar comandos.

## Estado de este procedimiento

La instalación v2 asumía una cuenta destino independiente y rechazaba configuraciones de cliente ya existentes para evitar mezclarlas con sus artifacts. Ese flujo fue reemplazado y sus opciones ya no forman parte de la sintaxis vigente del instalador.

## Instalación actual

- Para instalar Pegasus directamente en la cuenta Linux actual, seguí [INSTALL.md](../INSTALL.md).
- Si un agente asiste a la persona durante la instalación, seguí [INSTALL_BY_AGENT.md](../INSTALL_BY_AGENT.md).

Ambas guías vigentes describen la validación del checkout, el plan/apply y las decisiones explícitas para MCPs opcionales.

## Referencia operativa de v2

Las indicaciones de validación, desinstalación y preparación de cuentas que pertenecían a v2 se conservan solo como antecedente de esa versión. No las ejecutes contra un checkout actual; usá los procedimientos de instalación y rollback documentados en las guías vigentes.
