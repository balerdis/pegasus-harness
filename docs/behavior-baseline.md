# Phase-1 Behavior Baseline

The frozen source retains Pegasus identity, command names, SDD author metadata,
Engram and CBM guidance, manual artifact-store status routing, evidence
precedence, and the direct `sdd-verify` executor boundary.

The retired graph tool is absent. Transaction-based native review is disabled:
fresh-context `sdd-verify` remains the normal verification authority.

This is a source freeze, not a claim that the portable placeholders are ready
for activation.
